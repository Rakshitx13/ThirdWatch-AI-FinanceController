# Contributing to ThirdWatch

1. Create a focused branch and keep unrelated changes out of the pull request.
2. Use Node.js 24.19.0 and pnpm 11.19.0.
3. Install with `pnpm install --frozen-lockfile`.
4. Never add secrets or real financial records.
5. Run `pnpm run typecheck`, `pnpm run test:all`, `pnpm run build`, and `pnpm run validate:release`.
6. Document behavior, security, deployment, or data-handling changes.
7. Obtain review for changes to matching rules, financial calculations, authentication boundaries, release configuration, and dependency versions.

The repository has no selected software license. Contribution terms must be resolved by the repository owner before accepting outside contributions.
